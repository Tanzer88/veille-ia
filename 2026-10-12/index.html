L’actualité majeure

Les agents personnels deviennent un canal client

AccessibleAnnoncé le 9 octobre 2026

Ce qui change. Des agents IA personnels comme Muse (Meta), Dots (OpenAI) ou Instinct AI s'imposent comme intermédiaires entre les consommateurs et les entreprises. Instinct AI, accessible sur invitation seulement, déclare près d'un milliard de dollars de transactions annuelles selon son fondateur — sans application dédiée, par simple texto ou appel. Pour les entreprises, cela signifie qu'un client peut déléguer une recherche ou un achat à un agent qui interagit directement avec leurs systèmes.

Pourquoi c’est important. Si vos clients commencent à confier leurs achats à un agent personnel, votre visibilité dépend de la façon dont cet agent accède à votre catalogue, vos disponibilités ou vos tarifs. Les entreprises qui structurent leurs données et leurs offres pour une consommation par agents tiers prennent une longueur d'avance sur celles qui n'y pensent pas encore.

Limites. Article d'analyse de Salesforce, pas d'annonce produit. Les agents cités opèrent principalement aux États-Unis ; présence en francophonie non précisée. Le chiffre d'Instinct AI provient de son fondateur, cité par Salesforce — non vérifié de façon indépendante. Le Canada n'est pas mentionné.

Nouveautés utiles

Copilot pour JetBrains : plus de contrôle sur les modèles et le MCP

AccessibleAnnoncé le 10 octobre 2026

Ce que c’est. La mise à jour du plug-in GitHub Copilot pour JetBrains apporte la sélection du modèle par défaut, la configuration du serveur MCP, une meilleure navigation dans le chat et une fiabilité accrue des sessions en mode agent.

Pour quoi faire. Les équipes de développement sur IntelliJ, WebStorm ou PyCharm peuvent homogénéiser leur usage de Copilot : les administrateurs d'entreprise choisissent quel modèle s'active par défaut pour tous les membres, et le passage d'un bug signalé à une proposition de correctif demande moins d'étapes.

Prix. non précisé par la source (inclus dans les abonnements GitHub Copilot existants)

Limites. Nécessite JetBrains IDE 2025.2 ou ultérieur. L'IDE 2025.1 n'est plus pris en charge par le plug-in.

Amazon Bedrock : modèles OpenAI en accès général et nouveaux outils Strands

AccessibleAnnoncé le 9 octobre 2026

Ce que c’est. Le bilan AWS de septembre 2026 confirme la disponibilité générale des modèles OpenAI (Astra, Sol, Luna) sur Amazon Bedrock, l'aperçu public de Bedrock Managed Agents, et la sortie en open source de Strands Decider 2B — un petit modèle de décision rapide (~115 ms en local) qui choisit entre des options prédéfinies plutôt que de générer du texte.

Pour quoi faire. Les agences qui développent des applications IA sur AWS peuvent désormais choisir parmi une gamme étendue de modèles, dont les modèles OpenAI, sans gérer l'infrastructure d'inférence. Strands Decider 2B convient aux flux de travail où la rapidité de décision compte plus que la génération de contenu.

Prix. non précisé par la source

Limites. Récapitulatif mensuel : certains éléments peuvent déjà être connus des lecteurs assidus. Bedrock Managed Agents reste en aperçu public. Disponibilité au Canada non précisée par la source.

Cas d’usage

Une base de connaissances agence qui se tient à jour toute seule

Le problème. Une petite agence accumule des articles de veille, des briefs clients, des notes de réunion et des références dans des outils disparates. Retrouver la bonne information au bon moment prend du temps et la capitalisation collective reste superficielle.

La démarche. 1) Cloner le dépôt second-brain-os et ouvrir le vault de démarrage dans Obsidian. 2) Connecter Claude Code comme agent au vault en suivant le guide fourni. 3) Alimenter la boîte d'entrée (articles, PDF, notes brutes). 4) Laisser l'agent créer les pages wiki, établir les liens entre concepts et écrire les résumés. 5) Interroger le vault par le chat pour préparer un brief ou retrouver un précédent.

Les outils. second-brain-os (R1), Obsidian (gratuit), Claude Code

L’effort. Modéré à l'installation (clonage, configuration d'Obsidian, connexion de l'agent) ; faible ensuite pour l'alimentation quotidienne.

Le résultat attendu. Un vault Obsidian en fichiers Markdown, interrogeable par l'agent, qui relie automatiquement les nouveaux contenus aux thèmes déjà présents. La connaissance devient consultable même par les membres qui n'ont pas participé à la collecte initiale.

Limites. Nécessite un accès à Claude (abonnement ou API). La qualité des liens dépend de la régularité de l'alimentation. Aucune release officielle dans le dépôt : la configuration initiale de l'agent demande une lecture attentive de la documentation.

Le dépôt GitHub

KKKKhazix/AIHOT

À quoi il sert. Créer un site de veille automatisé pour votre secteur : l'outil collecte des sources configurables, filtre les contenus via un modèle de langage, regroupe les sujets similaires par popularité et publie une note quotidienne. Utile pour une agence qui veut offrir une veille sectorielle à ses clients ou alimenter une newsletter interne.

Prérequis. Docker, Node.js, accès à une API LLM (variable LLM_BASE_URL à configurer). Aisance minimale avec la ligne de commande et les fichiers de configuration.

Licence. MIT

Maintenance. Dernier push récent, aucune release officielle. Projet actif : il s'agit du moteur en production du site aihot.news, synchronisé au fil des mises à jour.

Difficulté. moyenne

Limites. README principalement en chinois simplifié, avec une version anglaise disponible ; aucune documentation en français. Le projet est exporté depuis une instance de production : certaines fonctionnalités spécifiques à l'auteur ne sont pas incluses dans la version open source.
