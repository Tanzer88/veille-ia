Gmail AI Inbox arrive chez les abonnés Workspace payants

AccessibleAnnoncé le 15 octobre 2026En vigueur : déploiement progressif depuis le 12 octobre 2026 (Rapid Release) ; Scheduled Release à partir du 26 octobre 2026

Ce qui change. Gmail met en avant les tâches à traiter en priorité et résume les mises à jour importantes directement dans la boîte de réception. La fonctionnalité identifie les courriels actionnables et les regroupe pour faciliter le traitement, sans modifier l'interface habituelle ni exiger de changement de flux de travail.

Pourquoi c’est important. Pour un dirigeant ou une équipe en agence qui reçoit un volume élevé de courriels professionnels, cette mise en avant automatique réduit le temps de tri et l'effort nécessaire pour repérer ce qui requiert une réponse rapide — directement dans l'outil déjà utilisé, sans passer par une application tierce.

Limites. Déploiement progressif : jusqu'à 15 jours pour la visibilité sur les domaines Rapid Release, Scheduled Release à partir du 26 octobre. Les éditions Starter et Education suivront dans les prochains mois. La disponibilité au Canada n'est pas précisée par la source. Gmail Live, déployé simultanément selon S28, est une fonctionnalité distincte (diffusion en direct depuis Meet).

GitHub Copilot corrige automatiquement les alertes de sécurité du code

AccessibleAnnoncé le 15 octobre 2026

Ce que c’est. La correction agentique des alertes de code scanning est désormais en disponibilité générale. Copilot explore la base de code, propose un correctif, vérifie que l'alerte est bien fermée via CodeQL, puis ouvre une pull request pour révision humaine avant fusion.

Pour quoi faire. Une agence ou une équipe de développement peut sélectionner jusqu'à 25 alertes de sécurité à la fois et confier leur correction à Copilot, puis réviser une seule PR plutôt que de traiter chaque alerte manuellement. Cela convient particulièrement aux équipes qui maintiennent plusieurs bases de code clientes.

Prix. non précisé par la source (inclus dans GitHub Code Security et GitHub Advanced Security)

Limites. Réservé aux abonnés GitHub Code Security et GitHub Advanced Security sur GitHub Enterprise Cloud, y compris avec résidence des données. Non disponible sur les plans individuels ni pour les organisations sans Enterprise Cloud.

Reflection Beam : modèle de codage agentique en poids ouverts, disponible sur AWS

AccessibleAnnoncé le 16 octobre 2026

Ce que c’est. Reflection AI publie Beam sous licence Apache 2.0, un modèle conçu pour les tâches de codage longues : maintenance de code, usage d'outils, workflows multi-étapes. Il compte 501 milliards de paramètres totaux (23 milliards actifs) et supporte une fenêtre de contexte d'un million de tokens.

Pour quoi faire. Une équipe technique peut déployer Beam via Amazon SageMaker JumpStart ou Hugging Face pour automatiser la révision ou la refactorisation de bases de code volumineuses, en conservant les données dans sa propre infrastructure plutôt que de passer par un service cloud tiers.

Prix. non précisé par la source (coûts d'infrastructure AWS à la charge de l'utilisateur)

Limites. Modèle très volumineux nécessitant une infrastructure GPU significative. Disponible initialement dans la région AWS US East (N. Virginia) via SageMaker JumpStart. Licence Apache 2.0. Peu adapté à une petite structure sans équipe technique dédiée.

Le dépôt GitHub

kajisho5/ffmpeg-skill

À quoi il sert. Donne à un agent de code (Claude Code, Cursor, Codex ou tout client MCP) un accès direct à 42 opérations FFmpeg locales : découpe, ajout de sous-titres, recadrage, normalisation du niveau sonore, export aux formats des principales plateformes. Une agence de contenu peut ainsi demander à son agent de reformater automatiquement une vidéo pour Instagram ou YouTube sans passer par un service cloud, sans clé API externe et sans que les fichiers quittent la machine.

Prérequis. Node.js (exécution via npx), Python 3, FFmpeg installé localement. Un agent de code compatible MCP (Claude Code, Cursor, Codex) est requis pour piloter les outils.

Licence. MIT

Maintenance. Dernier push et release v2.10.4 le 17 octobre 2026 ; dépôt actif, 1 981 étoiles.

Difficulté. élevée

Limites. La configuration initiale exige des compétences techniques (Node.js, Python, FFmpeg). L'outil est conçu pour être piloté par un agent de code, pas utilisé directement en ligne de commande sans celui-ci. La commande de diagnostic intégrée (npx ffmpeg-skill doctor) permet de valider l'installation pas à pas.
