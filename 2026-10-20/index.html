Copilot : pilotez vos modèles IA par API, récaps Meet et analyse vidéo

GitHub ouvre une API REST pour piloter programmatiquement les politiques de modèles Copilot à l'échelle d'une organisation. Côté Google Workspace, les réunions atterrissent désormais dans Google Chat sous forme de résumé structuré. Et pour les équipes qui produisent de la vidéo, le modèle Pegasus 1.5 de TwelveLabs est maintenant disponible sur Amazon Bedrock.

GitHub : API REST pour gérer les politiques de modèles Copilot

AccessibleAnnoncé le 19 octobre 2026

Ce qui change. Les endpoints GET et PATCH pour les politiques de modèles Copilot sont disponibles en disponibilité générale via l'API REST, à quatre niveaux distincts : entreprise, équipe d'entreprise, application d'entreprise et organisation. Il devient possible de récupérer et de modifier programmatiquement quels modèles IA les membres d'une organisation sont autorisés à utiliser dans Copilot.

Pourquoi c’est important. Pour une agence ou une PME qui déploie GitHub Copilot à plusieurs collaborateurs, cela permet d'intégrer la gestion des accès aux modèles IA dans ses propres scripts d'administration ou outils de provisionnement, sans intervention manuelle dans l'interface GitHub. On peut notamment restreindre l'accès à certains modèles selon les équipes ou les projets.

Limites. Requiert un abonnement GitHub Copilot pour entreprise ou organisation. La source ne précise pas les pays couverts ni les tarifs associés.

AccessibleAnnoncé le 19 octobre 2026En vigueur : Déploiement progressif : Rapid Release depuis le 16 octobre 2026, Scheduled Release à partir du 27 octobre 2026

Pegasus 1.5 : analyse de vidéos longues avec segments horodatés sur Amazon Bedrock

AccessibleAnnoncé le 19 octobre 2026

Ce que c’est. Pegasus 1.5 de TwelveLabs est un modèle vidéo qui parcourt une vidéo entière, repère chaque segment correspondant à des critères définis par l'utilisateur et retourne les résultats en JSON structuré avec horodatage de début et de fin. Les vidéos sont transmises directement depuis Amazon S3, sans pré-indexation.

Pour quoi faire. Une agence de contenu ou de communication peut automatiser la recherche de moments précis dans des vidéos longues — interviews, formations, captations d'événements — sans visionnage manuel. Le résultat JSON peut ensuite alimenter un système de gestion de médias ou un pipeline d'édition.

Prix. non précisé par la source

Limites. Nécessite un compte AWS et l'accès à Amazon Bedrock. Les régions disponibles et les tarifs ne sont pas précisés par la source.

Sorties structurées pour tous les modèles Claude sur Amazon Bedrock

AccessibleAnnoncé le 19 octobre 2026

Ce que c’est. Amazon Bedrock prend maintenant en charge les sorties structurées JSON conformes à un schéma défini pour tous les modèles Claude, via deux mécanismes : préfixe de JSON et validation de schéma (JSON Schema Draft 2020-12). Les grammaires compilées sont mises en cache 24 heures par compte.

Pour quoi faire. Extraire automatiquement des données structurées depuis des emails clients, des formulaires ou des documents sans écrire de code de parsing ni gérer des tentatives de réessai en cas de réponse malformée.

Prix. non précisé par la source

Limites. Requiert un compte AWS et l'accès aux modèles Claude sur Amazon Bedrock. Les régions et les tarifs ne sont pas précisés par la source.

Cas d’usage

Analyser et partager des données clients depuis son téléphone

Le problème. Une agence ou une PME reçoit régulièrement des données à analyser — résultats de campagne, métriques de projet, retours clients — et veut pouvoir en tirer des conclusions rapides en déplacement, puis les partager avec le client sans attendre d'être au bureau.

La démarche. 1. Ouvrir la feuille de calcul dans Google Sheets sur iPhone ou iPad. 2. Taper l'icône Gemini et poser des questions en langage naturel sur les données : tendances, anomalies, résumé des écarts. 3. Demander la création d'un graphique ou d'un tableau de synthèse depuis cette interface mobile. 4. Dans la Gemini app, assembler une mini-app interactive à partir de ces éléments. 5. Exporter cette app vers Google Sites en un clic et envoyer le lien au client.

Les outils. Gemini dans Google Sheets sur iOS (C6) ; publication d'apps interactives Gemini vers Google Sites (C8)

L’effort. Faible à modéré — aucune configuration technique supplémentaire pour les utilisateurs Workspace éligibles. Le déploiement de Gemini dans Sheets sur iOS est progressif et peut ne pas être visible immédiatement pour tous.

Le résultat attendu. Un rapport interactif partageable produit en quelques minutes depuis un téléphone, sans passer par un outil tiers ni attendre une session de travail au bureau.

Limites. Fonctionnalités réservées aux comptes Google Workspace éligibles. Gemini dans Sheets sur iOS est en déploiement progressif démarré le 15 octobre 2026. La publication vers Google Sites est disponible sur web, Android et iOS. Les niveaux d'offre exacts et les langues prises en charge ne sont pas détaillés par les sources.
