GitHub lance un pare-feu contre les attaques sur les paquets

Accès limitéAnnoncé le 20 octobre 2026

Ce qui change. GitHub intercepte désormais les requêtes d'installation de paquets (npm, pip, etc.) sur les runners Actions et les agents de code, avant même qu'un paquet soit téléchargé. Le pare-feu vérifie la présence de maliciels dans la GitHub Advisory Database, applique une période de refroidissement configurable pour les paquets récents et contrôle les attestations de chaîne d'approvisionnement.

Pourquoi c’est important. Les attaques sur les dépendances volent des identifiants lors de l'installation, sans que le code du paquet soit jamais exécuté. Pour une agence qui gère plusieurs bases de code client ou qui automatise ses pipelines CI/CD, ce point de contrôle réduit la surface d'exposition sans modifier les workflows existants.

Limites. Disponible en préversion publique uniquement pour GitHub Enterprise Cloud, y compris la version avec résidence de données. Gratuit pendant la préversion. L'infrastructure est en cours de montée en charge et des fonctionnalités supplémentaires sont annoncées. Le Canada n'est pas mentionné spécifiquement.

Smartsheet MCP : des agents IA dans votre gestion de projets

AccessibleAnnoncé le 20 octobre 2026

Ce que c’est. Smartsheet lance un serveur MCP (Model Context Protocol) en disponibilité générale, exposant plus de 40 outils pour explorer, créer et gérer feuilles, lignes, colonnes et automatisations via un agent IA.

Pour quoi faire. Un agent connecté à ce serveur — via Amazon Quick, Kiro ou tout client MCP compatible — peut consulter l'état d'un portefeuille de projets, mettre à jour des délais, réassigner des tâches ou produire un résumé de statut, sans que quiconque change d'outil.

Prix. non précisé par la source

Limites. Nécessite un compte Smartsheet et un client MCP compatible. Authentification via OAuth 2.0 ou jeton d'accès personnel. Trois points de terminaison régionaux disponibles. Le Canada n'est pas mentionné.

ChatGPT Work : un franchisé réduit de 95 % le temps de mise à jour de ses menus

AccessibleAnnoncé le 20 octobre 2026

Ce que c’est. OpenAI publie le cas d'un franchisé indépendant (Schlotzsky's et Cinnabon) qui a automatisé la mise à jour de ses menus et la réconciliation de trésorerie avec ChatGPT Work.

Pour quoi faire. Construire dans ChatGPT Work des flux récurrents — mise à jour de tarifs, réconciliation de caisse — pour remplacer la saisie manuelle dans plusieurs systèmes. Selon la source, le franchisé a réduit de 95 % le temps consacré à la mise à jour des menus et a construit un flux de travail susceptible de libérer des liquidités.

Prix. non précisé par la source

Limites. Source publiée par OpenAI (format témoignage). Les gains cités sont des estimations du franchisé, non vérifiées de façon indépendante. Les détails de mise en œuvre ne sont pas décrits dans la source. Le Canada n'est pas mentionné.

OpenCode ou Claude Code : guide de choix pour les équipes de développement

AccessibleAnnoncé le 19 octobre 2026

Ce que c’est. Zapier publie une comparaison entre OpenCode (outil open source, modèle BYOK) et Claude Code (CLI d'Anthropic), couvrant fonctionnalités, tarifs et cas d'usage.

Pour quoi faire. OpenCode convient si la flexibilité tarifaire est prioritaire (paiement à l'usage, choix libre du modèle) ; Claude Code est préférable si l'intégration avec l'écosystème Anthropic est centrale. Utile pour une agence web qui cherche à standardiser l'outillage de ses développeurs.

Prix. OpenCode : plan Go à 10 $/mois ou recharge de 20 $ pour les modèles plus puissants. Claude Code : abonnement Pro à 20 $/mois ; les modèles les plus puissants nécessitent le plan Max. (Montants en dollars américains.)

Limites. Comparaison datée d'octobre 2026 ; les disponibilités de modèles et les tarifs évoluent rapidement. Le support OAuth d'OpenCode a été bloqué par Anthropic en mars 2026 selon la source.

Le dépôt GitHub

n8n-io/n8n

À quoi il sert. Créer et déployer des agents IA et des workflows d'automatisation qui connectent outils, données et modèles — sans code ou avec du code selon le besoin. Adapté à l'automatisation marketing, à la gestion de leads, aux pipelines de données et aux agents personnalisés sur plus de 1 500 intégrations.

Prérequis. Docker ou Node.js pour l'auto-hébergement. Disponible aussi en mode hébergé via n8n.cloud. Connaissances de base en APIs et automatisation.

Licence. NOASSERTION (fair-code)

Maintenance. Dernier push et version n8n@2.44.5 publiés le jour de cette édition ; projet non archivé et très actif.

Difficulté. moyenne

Limites. La licence fair-code impose des restrictions à l'usage commercial à grande échelle ; à vérifier avant déploiement en production. L'auto-hébergement nécessite des compétences en administration Docker. Certaines intégrations avancées peuvent requérir des plans payants.
