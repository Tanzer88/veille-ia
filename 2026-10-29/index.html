L’actualité majeure

GitHub Agentic Workflows : disponibilité générale

AccessibleAnnoncé le 28 octobre 2026En vigueur : 28 octobre 2026

Ce qui change. GitHub Agentic Workflows passe en disponibilité générale sur GitHub Free, Team et Enterprise. Vous décrivez vos automatisations en langage naturel dans un fichier Markdown — triage d'issues, analyse d'échecs de CI, mise à jour de documentation, écriture de tests — et l'outil compile le tout en YAML standard pour GitHub Actions. Aucune configuration manuelle du pipeline requise.

Pourquoi c’est important. Une agence ou une équipe technique peut confier des tâches répétitives de maintenance à des agents GitHub sans changer d'outil ni écrire de YAML à la main. Les automatisations restent dans le dépôt, lisibles et versionnées comme n'importe quel autre fichier.

Limites. Les chiffres cités par GitHub (29 h économisées par semaine pour un responsable, 91 % des commits rédigés par IA, erreurs de production réduites d'environ 11 000 à moins de 1 000 par jour) proviennent d'une équipe interne de l'entreprise — ils ne sont pas généralisables. La qualité des résultats dépend de la précision des descriptions en langage naturel fournies.

Copilot inclus dans GitHub Enterprise

Accès limitéAnnoncé le 28 octobre 2026

Ce que c’est. GitHub Enterprise intègre désormais l'accès à GitHub Copilot pour chaque utilisateur licencié, sans gérer un quota de sièges séparé. La facturation bascule vers un suivi de la consommation budgétaire globale de l'entreprise.

Pour quoi faire. Pour les PME ou agences déjà sous contrat GitHub Enterprise avec une équipe de compte GitHub ou Microsoft, plus besoin de jongler entre deux abonnements. Les utilisateurs sans licence Enterprise conservent l'accès via Copilot Standalone.

Prix. $10 par utilisateur par mois pour Copilot Standalone (utilisateurs sans licence Enterprise)

Limites. Disponible maintenant uniquement pour les clients GitHub Enterprise Cloud ayant une équipe de compte GitHub ou Microsoft. L'accès en libre-service sera déployé progressivement ; les dates ne sont pas encore communiquées. Le Canada n'est pas précisé par la source.

Slack Code API : ouverte à tous les développeurs

AccessibleAnnoncé le 28 octobre 2026En vigueur : 28 octobre 2026

Ce que c’est. La Slack Code API permet à n'importe quel agent IA d'ouvrir un canal Slack dédié à une tâche de code — y ajouter les personnes et fichiers pertinents, poster des mises à jour en temps réel et archiver le canal à la fermeture du travail.

Pour quoi faire. Une agence peut connecter son propre agent (déploiement, revue de code, analyse de bug) à Slack pour que l'équipe suive l'avancement sans quitter son espace de travail habituel. Disponible sur tous les plans Slack.

Prix. non précisé par la source

Limites. Nécessite des compétences de développement pour intégrer l'API. La source ne précise pas les régions ou langues concernées.

Fill with Gemini : citations par cellule et traitement étendu dans Google Sheets

AccessibleAnnoncé le 28 octobre 2026En vigueur : déploiement progressif (démarré le 20 octobre, jusqu'à 15 jours de visibilité)

Ce que c’est. La fonction IA de Google Sheets affiche maintenant la source web exacte pour chaque cellule générée. La capacité passe à 3 000 cellules par requête.

Pour quoi faire. Une agence ou une PME qui collecte et classe des données (comparatifs, veille concurrentielle) peut vérifier chaque valeur générée directement dans la cellule, sans sortir de Sheets.

Prix. non précisé par la source (fonctionnalité incluse dans Gemini in Sheets)

Limites. Disponible sur le web uniquement pour les utilisateurs ayant Gemini in Sheets activé. La comparaison de vitesse citée provient d'une étude interne de 95 participants — résultats non généralisables. Le Canada n'est pas précisé par la source.

Cas d’usage

Traiter le code confidentiel localement avec Copilot Fusion

Le problème. Une agence qui travaille sur du code client sensible hésite à envoyer ce code vers des services IA cloud. Désactiver l'assistance IA nuit à la productivité ; l'activer fait courir un risque de confidentialité.

La démarche. 1. Activer la préversion expérimentale de Copilot Fusion dans les paramètres du compte. 2. Configurer un modèle local : MAI Code 1.1 Flash via Windows ML (Windows uniquement) ou Qwen3.8 Flash Next via un serveur local compatible OpenAI. 3. Copilot Fusion choisit automatiquement entre le modèle local et le modèle cloud selon la requête — sans changement manuel à chaque fois. 4. Les fichiers de code sensibles restent traités sur l'appareil.

Les outils. GitHub Copilot Fusion (C5)

L’effort. Moyen : la configuration Windows ML est guidée ; le serveur local OpenAI-compatible demande plus de préparation technique. L'opt-in reste manuel par utilisateur.

Le résultat attendu. L'équipe conserve l'assistance IA au quotidien tout en limitant l'exposition du code confidentiel aux services cloud, sans jongler entre plusieurs outils.

Limites. Préversion expérimentale (opt-in) — comportement susceptible de changer. Restreint aux appareils Windows pour la voie Windows ML ; les autres systèmes nécessitent un serveur local. Les performances locales dépendent des capacités matérielles de l'appareil. Le Canada n'est pas précisé par la source.

Le dépôt GitHub

tangency-labs/solidcraft

À quoi il sert. Logiciel de CAO paramétrique 3D open source, utilisable en local ou dans le navigateur. Un serveur MCP intégré permet à un agent IA de piloter la modélisation par commandes. Pertinent pour des équipes produit ou des agences qui créent des maquettes ou des pièces techniques sans abonnement à un outil propriétaire.

Prérequis. Binaires disponibles pour Windows, macOS et Linux — installation directe. La compilation depuis les sources nécessite Rust.

Licence. Apache-2.0

Maintenance. Dernier push et release v0.26.0 publiés le 29 octobre — projet actif.

Difficulté. faible

Limites. Usage niche : pertinent principalement pour les équipes qui travaillent sur des produits physiques ou des designs mécaniques. Le pilotage par agent via MCP est une fonctionnalité avancée qui nécessite une configuration supplémentaire.

En bref

  • OpenAI et ServiceNow élargissent leur partenariat : les modèles OpenAI s'intègrent aux workflows ServiceNow, et les workflows ServiceNow arrivent dans ChatGPT Work et Codex. À suivre pour les PME qui utilisent ServiceNow pour leur support ou leurs opérations internes. (8)
  • n8n partage les leçons de son équipe d'automatisation interne : passé 12 000 workflows actifs, le modèle « service desk centralisé » ne tient plus. La direction adoptée — chaque équipe construit et maintient ses propres automatisations — s'applique aussi aux agences qui gèrent l'automatisation de leurs clients. (9)
  • Zapier publie AutomationBench, un benchmark qui mesure si un modèle IA peut terminer un workflow métier complet (ventes, marketing, finance, RH). Les résultats rejoignent le Specialized Intelligence Index de Fireworks — utile pour comparer les modèles avant de les intégrer dans vos automatisations. (10)
  • L'Octoverse 2026 comptabilise 17,9 milliards de push en douze mois sur GitHub, soit plus que 2024 et 2025 réunis. Selon GitHub, la croissance est portée par les agents qui rédigent et soumettent du code de façon autonome. (11)
