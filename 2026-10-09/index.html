L’actualité majeure

Gemini : un agent unique pour toutes vos applications de travail

Accès limitéAnnoncé le 8 octobre 2026

Ce qui change. Google a présenté un agent Gemini capable d'opérer depuis une interface et une API uniques, en maintenant la même mémoire d'un canal à l'autre — Gmail, Drive, Docs, Sheets, Calendar, Slack, Microsoft 365, appareils mobiles, bureau et ligne de commande. Il répond à des questions, traite des tâches de connaissance, crée des images et exécute du code depuis ce point d'entrée commun.

Pourquoi c’est important. Pour une PME ou une agence qui jongle entre plusieurs outils, un agent qui garde le contexte d'une session à l'autre et peut agir directement dans les applications déjà utilisées réduit le besoin de passer d'une interface à l'autre pour déléguer des tâches répétitives.

Limites. Disponible en private preview pour les clients Gemini Enterprise uniquement. Les verticales finance et juridique sont en preview ; secteur public, santé et retail sont annoncés sans date précise. Aucune mention explicite du Canada ni de la disponibilité en français dans les sources.

GitHub Copilot : l'exécution sandboxée passe en disponibilité générale

AccessibleAnnoncé le 7 octobre 2026

Ce que c’est. Les workflows agentiques de Copilot s'exécutent désormais dans un bac à sable local qui restreint l'accès au système de fichiers, au réseau et aux identifiants de la machine, selon des règles définies par le développeur ou l'organisation.

Pour quoi faire. Pour une agence de développement, cela permet de laisser Copilot exécuter des tâches automatiques — générer des fichiers, lancer des scripts — sans risquer qu'il accède à des clés d'API ou à des répertoires sensibles en dehors du périmètre défini.

Prix. Inclus dans GitHub Copilot sans frais additionnels

Limites. Disponible dans Copilot CLI, l'application Copilot et VS Code avec Agent Host. Non mentionné pour JetBrains ou d'autres IDE.

EmbeddingGemma 2 : recherche multimodale open source, utilisable en local

AccessibleAnnoncé le 6 octobre 2026

Ce que c’est. Google DeepMind lance EmbeddingGemma 2, un modèle d'embedding de 740 millions de paramètres capable de représenter du texte, des images, de l'audio, de la vidéo et du code dans un espace vectoriel commun. Licence Apache 2.0, conçu pour l'inférence sur appareil.

Pour quoi faire. Une PME peut l'utiliser pour construire un moteur de recherche interne sur ses propres documents, images et fichiers audio sans envoyer ses données à un service tiers — un atout pour la confidentialité.

Prix. Gratuit (open source Apache 2.0)

Limites. Nécessite des compétences en développement Python pour l'intégration. Conçu pour l'inférence locale ; aucun service cloud clé en main n'est mentionné dans la source. Compatibilité avec des plateformes ou services canadiens non évoquée.

GitHub : un modèle IA dédié à la détection de secrets dans le code

Accès limitéAnnoncé le 7 octobre 2026

Ce que c’est. GitHub déploie un modèle entraîné spécifiquement pour détecter les secrets exposés (clés API, tokens) dans le code, intégré à push protection et aux revues de sécurité Copilot.

Pour quoi faire. Pour une agence ou une PME qui utilise GitHub, activer cette fonctionnalité permet de bloquer automatiquement les commits qui contiendraient des identifiants sensibles avant qu'ils ne soient publiés dans le dépôt.

Prix. Disponible pour GitHub Enterprise Cloud ou GitHub Teams avec achat de GHSP ou GHAS. La facturation commence dès l'activation par l'organisation.

Limites. La détection dans push protection est en private preview. La fonctionnalité pour Copilot CLI et l'application Copilot est annoncée bientôt en private preview. Réservé aux offres Enterprise Cloud ou Teams avec modules de sécurité additionnels.

Cas d’usage

Automatiser la documentation de design et les variations de maquettes avec l'agent Figma

Le problème. Dans une agence, documenter les systèmes de design et produire des variations de maquettes est chronophage : chaque composant doit être annoté manuellement, et explorer plusieurs directions visuelles pour un client multiplie le nombre de fichiers à gérer.

La démarche. 1. Ouvrir le projet dans Figma avec l'agent activé. 2. Utiliser des commandes en langage naturel pour générer automatiquement la documentation d'un composant (structure, couleurs, tokens). 3. Demander des variations de mise en page ou de texte pour un même écran sans dupliquer le fichier manuellement. 4. Faire valider les livrables par le directeur artistique avant transmission au client ou à l'équipe de développement.

Les outils. Agent Figma (C18)

L’effort. Faible à modéré : les fonctions de base (variations, texte alternatif, documentation) sont disponibles sans configuration. La création de skills personnalisés pour des besoins spécifiques au système de design de l'agence demande des connaissances en développement Figma.

Le résultat attendu. La documentation de composants et l'exploration de variantes se font plus rapidement, libérant du temps pour le travail de conception à plus forte valeur ajoutée. La qualité et la cohérence de la documentation du système de design s'améliorent.

Limites. Disponibilité générale confirmée, mais la création de skills sur mesure reste technique. L'affirmation de performance sur les évaluations humaines est une affirmation commerciale. Prix non précisé par la source.

Le dépôt GitHub

ZJU-REAL/Easel

À quoi il sert. Agent open source de gestion de contenu pour les réseaux sociaux : découverte de tendances, rédaction, publication et analyse de performance. Couvre le cycle complet — de l'idée au bilan — en mémorisant le positionnement du compte, l'audience et les performances passées.

Prérequis. Python 3, Node.js, clé API Anthropic ou OpenAI (ou fournisseur compatible).

Licence. Apache-2.0

Maintenance. Actif — dernier push le 9 octobre 2026, dernière release v0.2.1 le 24 septembre 2026.

Difficulté. moyenne

Limites. Conçu en priorité pour les plateformes chinoises (Xiaohongshu, Douyin, Zhihu, Bilibili). La compatibilité avec Instagram, LinkedIn ou X n'est pas documentée dans les extraits disponibles. Le README et une partie de la documentation sont en chinois. La publication automatique sur certaines plateformes peut déclencher des mesures anti-automatisation selon le README.
