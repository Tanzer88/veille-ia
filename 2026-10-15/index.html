L’actualité majeure

Figma : code layers, Specs et guidelines en open beta

AccessibleAnnoncé le 15 octobre 2026En vigueur : déploiement progressif

Ce qui change. Code layers passe en open beta sur tous les plans : les équipes peuvent désormais travailler sur des couches de code directement dans le canvas Figma, aux côtés des éléments de design. Specs (documentation automatique des composants) et guidelines (règles de design partagées) sont également en open beta sur tous les plans payants. Code sources démarre en bêta fermée. Payload, un CMS open source intégré à Figma Make, se déploie progressivement sur tous les comptes dans les semaines à venir.

Pourquoi c’est important. Pour une agence web ou communication, le passage de la maquette au code devient plus direct : moins d'allers-retours entre designer et développeur, documentation des composants générée automatiquement, et la possibilité pour des équipes mixtes de collaborer sur le même fichier sans quitter Figma.

Limites. Code sources en bêta fermée : accès restreint. Specs, guidelines et Payload sont limités aux plans payants. Payload se déploie progressivement et ne sera pas disponible immédiatement sur tous les comptes. Le Canada n'est pas mentionné spécifiquement dans l'annonce.

HydraFusion Max arrive dans GitHub Copilot

Accès limitéAnnoncé le 14 octobre 2026

Ce que c’est. HydraFusion coordonne plusieurs modèles de différents fournisseurs pour produire une réponse unique à partir de leurs forces respectives. La nouvelle variante Max dispose d'un pool élargi et d'une orchestration améliorée ; les deux restent en research preview sur VS Code, l'application GitHub Copilot et le CLI.

Pour quoi faire. Pour une agence de développement, cela permet d'obtenir des réponses qui combinent les points forts de plusieurs modèles sans avoir à choisir manuellement lequel utiliser selon la tâche.

Prix. Non précisé par la source

Limites. Research preview uniquement. Requiert un plan Copilot Pro, Pro+, Business ou Enterprise avec les fonctionnalités expérimentales activées, selon la politique de modèles de l'organisation. Le Canada n'est pas mentionné spécifiquement.

MCP dans Apigee hybrid : les outils d'agents restent dans votre cluster

AccessibleAnnoncé le 14 octobre 2026

Ce que c’est. Google Apigee hybrid intègre désormais le protocole MCP, permettant à des agents IA d'appeler des outils internes sans que les requêtes ne sortent de l'infrastructure de l'organisation. Les endpoints MCP héritent des politiques de sécurité Apigee existantes : OAuth 2.0, OpenID Connect, vérification par clé API.

Pour quoi faire. Pour une agence ou une PME qui expose ses services internes via Apigee, cela permet de connecter des agents IA à ces services en conservant les contrôles d'accès déjà en place, sans ajouter de couche d'infrastructure.

Prix. Non précisé par la source

Limites. Requiert Apigee hybrid 1.17.0 ou version ultérieure et une opération Helm sur le cluster. Disponible pour les organisations en mode Subscription et Evaluation uniquement (dont Data Residency). Prérequis techniques élevés. Le Canada n'est pas mentionné spécifiquement.

Cas d’usage

Évaluer Gemini 4 Argon avant la hausse tarifaire du 1er décembre

Le problème. Une agence ou une PME veut tester Gemini 4 Argon pour des tâches complexes — analyse de documents volumineux, revue de code, structuration de contenu — mais hésite à investir du temps dans une intégration sans connaître les coûts réels en production.

La démarche. 1. Créer un accès via Google AI Studio ou l'API Gemini, accessible maintenant pour les développeurs et les entreprises. 2. Identifier un ou deux cas d'usage internes représentatifs : résumé de rapports clients, analyse d'un fichier de données long, ou première passe de revue de code. 3. Lancer quelques tests avec le tarif actuel d'introduction (2 USD par million de tokens en entrée, 10 USD par million en sortie) pour mesurer les volumes et calibrer le coût réel. 4. Documenter les résultats et décider avant le 1er décembre si l'intégration vaut la hausse tarifaire annoncée.

Les outils. Gemini 4 Argon via Google AI Studio ou l'API Gemini

L’effort. Faible pour un test via l'interface AI Studio ; moyen pour une intégration dans un flux de travail existant via l'API.

Le résultat attendu. Une évaluation concrète du modèle sur des tâches réelles de l'agence, avec une décision documentée sur l'intégration prise avant la hausse des prix.

Limites. Le doublement des prix au 1er décembre est rapporté par L'Usine Digitale (source secondaire, S17) et n'est pas confirmé dans les sources primaires Google disponibles dans ce dossier. L'accès mondial à l'API est confirmé par Google (S7) ; le Canada est inclus. Les tarifs en production peuvent varier selon les niveaux d'utilisation.

Le dépôt GitHub

nano-muse/nanoMuse

À quoi il sert. Agent personnel open source déployable sur Android, iOS, Windows, macOS, Linux et navigateur. Il exécute des tâches en arrière-plan, conserve un contexte entre les sessions et demande une confirmation avant toute action irréversible. Une PME ou une agence peut l'auto-héberger pour expérimenter un assistant interne sans dépendre d'un service tiers.

Prérequis. Docker (mentionné dans le README) ; compétences de déploiement de base pour héberger le relay qui relie les différents clients.

Licence. GPL-3.0

Maintenance. Dernier push le 15 octobre, release v1.0.5 le 13 octobre ; projet actif.

Difficulté. moyenne

Limites. Licence GPL-3.0 : toute modification doit être redistribuée sous la même licence, ce qui peut contraindre un usage commercial propriétaire. L'installation n'est pas documentée directement dans le README.

En bref

  • Tottenham Hotspur a unifié 4,6 millions de comptes supporters sur plus de 10 systèmes avec Salesforce Agentforce, et son agent Ask Spurs affiche un taux d'engagement de 86 %, avec 20 % des interactions résolues sans intervention humaine. Le cas illustre ce qu'une architecture CRM agentique peut produire pour toute organisation gérant une large base de contacts. (7)
  • Selon une étude YouGov commandée par Meta auprès de près de 4 000 petites entreprises dans neuf marchés APAC, 84 % utilisent déjà l'IA et 76 % rapportent un impact positif sur la productivité. Les usages les plus cités : création ou édition de contenu (51 %), publicité locale (43 %), support client (37 %). Le Canada n'est pas inclus dans l'étude. (8)
  • Salesforce a signé un accord pour acquérir Loops, une plateforme qui surveille les indicateurs métier en continu et explique automatiquement pourquoi ils changent. La transaction devrait se conclure début novembre ; l'intégration est annoncée avec Tableau. (9)
  • Withings restreint la synchronisation vers Apple Santé et Strava aux seuls abonnés Withings+ (9,99 €/mois) pour les nouveaux utilisateurs, au motif que la valeur réside désormais dans les données plutôt que dans le matériel. Selon Numerama, l'export CSV et PDF reste gratuit — un signal de la tendance à la monétisation des données dans les services connectés. (10)

Calibrez vos coûts API avant le 1er décembre — les tarifs d'introduction ne durent pas.
